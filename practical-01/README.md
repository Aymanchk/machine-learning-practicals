## Цель работы

Настроить рабочее окружение Python, загрузить табличный датасет и выполнить первичный анализ данных.

## Структура проекта

- `data/tips.csv` — исходный датасет;
- `notebooks/pr1_tips_analysis.ipynb` — notebook с анализом;
- `README.md` — описание практической работы.

## Окружение

Окружение `.venv` и общий `.gitignore` находятся в корне репозитория, на уровень выше папки практической.

Для работы выбрано виртуальное окружение `venv`, поскольку оно встроено в Python и позволяет изолировать зависимости проекта.

Использованные библиотеки:

- pandas;
- NumPy;
- Matplotlib;
- Jupyter;
- scikit-learn.

## Выполненный анализ

В работе выполнены:

- загрузка и просмотр данных;
- определение размера таблицы;
- анализ типов столбцов;
- проверка пропущенных значений;
- расчёт базовых статистик;
- визуализация распределения суммы счёта;
- сравнение количества посещений по дням недели;
- анализ связи суммы счёта и размера чаевых.

## Основные результаты

Датасет содержит 244 наблюдения и 7 признаков. Пропущенные значения отсутствуют. Распределение суммы счёта имеет правостороннюю асимметрию, большая часть наблюдений приходится на выходные дни, а между суммой счёта и размером чаевых наблюдается положительная связь.
