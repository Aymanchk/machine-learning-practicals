В этой работе настроил Python, загрузил данные о счетах и чаевых в ресторане и посмотрел их с помощью pandas и графиков.

## Данные

Использовал [Tips с Kaggle](https://www.kaggle.com/datasets/mitadrumridha/tips-csv). В таблице 244 строки и 7 столбцов. Пропусков нет.

## Файлы

- [Notebook с анализом](notebooks/pr1_tips_analysis.ipynb)
- [Данные tips.csv](data/tips.csv)

## Окружение

Выбрал `venv`: он уже есть в Python и позволяет устанавливать библиотеки отдельно для проекта.

Окружение `.venv` находится в корне общего репозитория. Инструкция по запуску есть в [общем README](../README.md).

## Что сделал

Посмотрел первые строки, размер таблицы, типы столбцов, пропуски и статистики. Построил три графика: распределение суммы счёта, количество записей по дням недели и связь счёта с чаевыми.

## Выводы

Большинство счетов небольшие, а крупные встречаются реже. На субботу и воскресенье приходится 66,8% записей. Чем больше счёт, тем обычно больше чаевые, но на графике есть заметный разброс. Эти выводы относятся к этой выборке.
