# Практическая работа № 4. Регрессионная модель

ФИО: Эркинбеков Айман

## О работе

В работе построена модель линейной регрессии для предсказания выбросов CO2 автомобилями.

Были обучены две модели:

- базовая модель со всеми числовыми признаками;
- сокращённая модель после удаления связанных признаков.

Для предобработки использован Pipeline с заполнением пропусков, масштабированием и one-hot кодированием.

## Датасет

Использован датасет [CO2 Emission by Vehicles](https://www.kaggle.com/datasets/debajyotipodder/co2-emission-by-vehicles) с Kaggle.

Целевая переменная: `CO2 Emissions(g/km)`.

## Структура

- `data/co2_emissions_canada.csv` - исходные данные;
- `notebooks/pr4_co2_regression.ipynb` - анализ и обучение модели.

## Результат

Модели сравниваются на валидационной части обучающих данных. Выбранная модель повторно обучается на всей обучающей выборке и оценивается на тестовой. Качество оценено с помощью MAE, MSE, RMSE и R2. Также построены график реальных и предсказанных значений и график остатков.
