## О работе

В работе построена модель линейной регрессии для предсказания выбросов CO2 автомобилями.

Были обучены три модели:

- базовая модель со всеми числовыми признаками;
- сокращённая модель после удаления связанных признаков (проверка через корреляционную матрицу и VIF);
- модель с учётом типа топлива: смешанный расход отдельно для каждого типа топлива.

Для предобработки использован Pipeline с заполнением пропусков, масштабированием и one-hot кодированием.

## Датасет

Использован датасет [CO2 Emission by Vehicles](https://www.kaggle.com/datasets/debajyotipodder/co2-emission-by-vehicles) с Kaggle.

Целевая переменная: `CO2 Emissions(g/km)`.

Перед обучением удалены полные дубликаты и единственный автомобиль на природном газе: по одной записи модель не может выучить этот тип топлива.

## Структура

- `data/co2_emissions_canada.csv` - исходные данные;
- `notebooks/pr4_co2_regression.ipynb` - анализ и обучение модели.

## Результат

Модели сравниваются на валидационной части обучающих данных. Выбранная модель повторно обучается на всей обучающей выборке и оценивается на тестовой. Качество оценено с помощью MAE, MSE, RMSE и R2. Также построены график реальных и предсказанных значений и график остатков по типам топлива.

График остатков показал, что одна общая прямая плохо подходит для разных видов топлива: у этанола ошибки были заметно больше. На валидации RMSE: базовая модель 6,33 г/км, сокращённая 6,94 г/км, модель с учётом типа топлива 2,87 г/км. По заранее заданному правилу выбрана модель с учётом типа топлива. На тесте MAE 2,26 г/км, RMSE 3,44 г/км, R² 0,997.
