# Практическая работа № 6. Классификация текстов

ФИО: Эркинбеков Айман

Вариант: B

Определяю тональность отзывов о фильмах. Взял корпус `movie_reviews` из библиотеки NLTK: 2000 отзывов на английском языке, по 1000 положительных и отрицательных. Копия лежит в папке `data`.

Текст чистил функцией `clean_text`: нижний регистр, раскрытие `n't`, удаление пунктуации и цифр, стоп-слова, стемминг Snowball. Отрицания (`not`, `no`, `never` и другие) из стоп-слов убрал, чтобы не потерять смысл отзыва. Векторизацию TF-IDF положил в `Pipeline`, чтобы словарь считался только по обучающей части. Значения `min_df` и `max_df` выбрал по F1 на кросс-валидации: `min_df=5`, `max_df=0.5`.

Размерность признакового пространства на обучении 1600 × 8176. На тесте accuracy 0,810 и F1 0,813. В notebook разобраны пять ошибок модели и написаны гипотезы о причинах.

Файлы:

- `data/reviews.csv` - отзывы и метки классов;
- `notebooks/pr6_text_classification.ipynb` - код, результаты и выводы.

Чтобы запустить работу, в окружении `.venv` нужна библиотека `nltk` (нужен только стеммер): `python -m pip install nltk`. Затем открой notebook в VS Code, выбери ядро `.venv`, выполни Restart и Run All. Вывод ячеек сохранён в файле.
